# Reproducing the paper

The library was developed together with the paper P. Torrente et al., *Factorized approximate inverse preconditioners in
the tensor train format* (in preparation), which introduces the factorized approximate inverse (FAI) preconditioner of
[`fai_preconditioner`](@ref) and tests it on the anisotropic elliptic operators of its Sec. 5.1 and on the Chorin
projection around a cylinder of its Sec. 5.2. The figures of the paper were generated by scripts that depend on the
state of the library at the time of the runs. For this reason we keep them in a frozen bundle, instead of updating them
with the library.

The bundle lives in the repository, in
[`experiments/paper`](https://github.com/bsc-quantic/DifferenTT.jl/tree/master/experiments/paper), and its
[`README.md`](https://github.com/bsc-quantic/DifferenTT.jl/blob/master/experiments/paper/README.md) lists, for each
figure and table, the script that produces it, the environment, and the SLURM settings of the runs on the cluster. It is
pinned to the tagged version `paper-ttfai-data` of the library (commit `6850540`), which is the version that produced
the data. Two consequences follow.

  - The library has changed since that tag. Several of the changes alter numbers (for instance the orientation of the
    FAI factor and the convention of the cutoff of [`ResidualALS`](@ref)), and the arguments of some functions changed,
    so the scripts of the bundle are meant to run against the tagged version and not against the current one. The
    changes are listed in the release notes (`NEWS.md`).
  - The data of the paper will be regenerated with the current version before submission, so numbers obtained today
    need not agree digit by digit with older runs. The tutorials, and the scripts of the other folders of
    `experiments`, are written for the current version.

The heavy runs of the paper need a cluster and are not part of the documentation build or of the tests. The experiment
scripts also have a smoke mode, with tiny sizes, which only checks that they run.
